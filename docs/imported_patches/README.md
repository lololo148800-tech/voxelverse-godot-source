## Что внутри

### `shaders/water_surface.gdshader` — ГОТОВЫЙ файл, можно просто заменить

Оригинал был 29 строк, единственная реальная правка — вторая строка
(`render_mode`):

- Было: `cull_disabled`
- Стало: `cull_back` + добавлен `depth_prepass_alpha`

Это чинит "лоскутные пятна" на воде — конфликт между `depth_draw_opaque`
и полупрозрачным (`blend_mix`) материалом при отрисовке обеих сторон
каждой грани.

**Как применить:** скопируй этот файл поверх
`res://shaders/water_surface.gdshader` в своём проекте — 1 в 1 замена.
