# Пепельный Рубеж · VoxelVerse — Godot Source Archive

This repository publishes the clean source archive for the VoxelVerse Godot 4.3 project.

The downloadable release asset contains the project source, original assets, data files, shaders, tests, build configuration, and documentation. Generated `.godot` and `build` directories, APK/EXE archives, and secret/key files are intentionally excluded.

## Open the project

1. Download the ZIP release asset.
2. Extract it.
3. Open the extracted folder in Godot 4.3.
4. Run `project.godot` and use `res://core/main_menu.tscn` as the main scene.
5. Run the parser/import pass before Android export.

The project uses Godot 4.3, GDScript, the GL Compatibility renderer, original voxel textures, chunk-backed voxel data, batched ArrayMesh rendering, mobile overlay controls, and Godot smoke/regression tests.

This archive does not contain Minecraft source code or Minecraft proprietary assets.
